## Problem Statement

Currently, lesson steps are mechanical: show a phrase, quiz on it, move on. The NPC character says "New phrase: Guten Tag" — which is dry and doesn't teach. The help button shows a static text hint. There's no sense of being guided by a tutor.

Additionally, when the AI generates a broken question (wrong language, mismatched pairs, missing answers), the user is stuck with no recourse.

---

## Vision

### AI Coaching Welcome (each lesson step)
Instead of "New phrase: Guten Tag", the NPC character delivers a rich, spoken coaching introduction:

> *"Hey! Welcome to this step. We're going to learn the German phrase 'Guten Tag', which means 'Hello' or literally 'Good day'. You can use it in a phrase like 'Guten Tag, mein Freund' which means 'Hello, my friend'. Let's learn them bit by bit!"*

The coaching text is:
- Generated by AI during lesson creation (not real-time)
- Personalised: references sundrop count, gem goals, user interests
- Spoken via TTS with mouth animation on the NPC avatar
- In the user's native language (with target language examples)

### Help System (voice-first)
When stuck, the user taps a prominent "Help" button:
1. Pre-recorded TTS plays: "Hey, what do you need help with?"
2. Screen blurs slightly (lesson still visible for reference)
3. Microphone activates with clear "speak now" indicator
4. User asks a question in free conversation
5. AI responds with contextual help (knows the lesson, user history, strengths/weaknesses)
6. Conversation continues until user closes help

### Broken Question Recovery
Two paths to recovery:

**Path A — Explicit "Report" button:**
1. User taps a "🚩 Report" button on any question
2. AI auto-regenerates the question with a validation check
3. User sees the fixed question (or a skip if regeneration also fails)
4. Original broken question logged to `question_reports` collection

**Path B — Conversational detection:**
1. User opens Help and describes the problem ("the matching answers are both in German")
2. AI recognises this is a content error, not a comprehension issue
3. AI explains the mistake and apologises: "Oh, you're right! That's my mistake — both sides shouldn't be in the same language. Let me fix that for you."
4. AI triggers question regeneration
5. Fixed question presented to user

## Step-by-Step Implementation

### Step 1 — AI Coaching Text Generation (at lesson creation time)

**File:** `src/services/lessonGeneratorV2.ts` or `src/services/aiPedagogyClient.ts`

Extend the lesson generation prompt to include a `coachingText` field for each step:

```typescript
// In the lesson generation prompt, for each step:
{
  "steps": [
    {
      "type": "info",
      "chunk": "Guten Tag",
      "coachingText": "Hey! On va apprendre la phrase allemande 'Guten Tag'...",
      "activity": { ... }
    }
  ]
}
```

The coaching text prompt should include:
```
For each lesson step, generate a 'coachingText' field: a warm, encouraging introduction
spoken by the NPC tutor character. This text will be read aloud via TTS.

Rules for coachingText:
- Written in {nativeLanguage}, with {targetLanguage} examples inline
- 2-4 sentences maximum (will be spoken aloud — keep it concise)
- For INFO steps: introduce the new phrase, explain meaning, give a usage example
- For QUIZ steps: briefly frame the challenge ("Let's see if you remember...",
  "Here's a tricky one...", "You got this!")
- Reference the user's progress when relevant: "You've already earned {sunDrops} sundrops!"
- Mention goals: "Just {stepsRemaining} more steps to complete this lesson!"
- Match the user's age group in tone
- NEVER use English unless the user's native language IS English
```

```typescript
async function regenerateQuestion(
  originalActivity: ActivityConfig,
  lessonContext: LessonContext,
  errorDescription?: string,
): Promise<RegenerationResult> {
  // Step 1: Generate replacement
  const prompt = buildRegenerationPrompt(originalActivity, lessonContext, errorDescription);
  const result = await AIProviderService.getProvider().complete({
    messages: prompt,
    jsonMode: true,
    temperature: 0.5, // Lower temp for more reliable output
  });
  
  const newActivity = parseActivityFromJSON(result.text);
  
  // Step 2: Validate (unit test on answers)
  const validation = validateActivity(newActivity);

}
```

### Step 8 — Conversational Question Regeneration

In the help AI response handler, detect the `[REGENERATE_QUESTION]` marker:

```typescript
// After receiving AI help response:
if (aiResponse.includes('[REGENERATE_QUESTION]')) {
  // Strip the marker from displayed text
  const displayText = aiResponse.replace('[REGENERATE_QUESTION]', '').trim();
  
  // Show the apology/explanation text
  addChatBubble(displayText);
  
  // Trigger regeneration
  const result = await regenerateQuestion(currentActivity, lessonContext);
  if (result.success) {
    onQuestionRegenerate(result.newActivity);
    addChatBubble(t('help.questionFixed')); // "I've fixed the question for you!"
  } else {
    addChatBubble(t('help.questionSkipped')); // "I couldn't fix it, let's skip this one."
    onSkip();
  }
}
```
