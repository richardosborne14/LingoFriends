# Task 3.4: Coaching Chat Step Type

**Status:** 🔲 Not started  
**Phase:** 3 (AI-Coached Learning)  
**Dependencies:** Task 3.2 (Chunk Family Architecture)  
**Estimated Time:** 8–10 hours  
**Priority:** High — transforms teach steps from flashcards to coached discovery

---

## Objective

Replace the static INFO step ("New phrase: Guten Tag") with an interactive **coaching chat** where the NPC guides the learner to discover the chunk through a brief, warm exchange. The learner is invited to hypothesise, notice patterns, and engage — not just read and tap "Next."

This implements the PEDAGOGY.md principle:

> "Replace Present-Practise-Produce with Observe-Hypothesise-Experiment"

And the coaching principle:

> "Help learners discover patterns themselves. Ask reflective questions."

---

The key differences:
1. **NPC speaks** — TTS plays the coaching text, mouth animation on avatar
2. **Discovery question** — learner is asked to notice something (non-graded)
3. **Pattern highlighting** — AI points out the reusable frame ("Ich habe")
4. **Personal connection** — references the learner's context (Luna)
5. **Warmth** — feels like a conversation, not a flashcard

## Architecture

The coaching chat step has TWO parts:

### Part A: Pre-generated Coaching Text (from lesson creation)

This is the NPC's monologue — generated by the *smart* AI model during `generateChunksForTopic()`, stored in the lesson plan, and played via TTS when the step starts. This is an enhancement of the existing `coachingText` field from Task 2.0.7.

**Why pre-generate?** Because it needs to be linguistically polished, reference the personal context, and the smart model (not Groq) should write it. TTS needs the text immediately — no waiting for an API call.

### Part B: Interactive Discovery Exchange (real-time)

After the TTS plays, the learner sees a simple interactive element — a discovery question. This is NOT a graded quiz. Getting it "wrong" gets encouragement, not failure.

**Two interaction patterns by age:**

| Age Group | Discovery Interaction |
|-----------|----------------------|
| **7-10** | Tap-to-choose: "Which word means 'cat'?" → [ Katze ] [ Habe ] [ Ich ] |
| **11-14** | Tap-to-choose OR free text: "Can you guess what 'Katze' means?" → free text input |
| **15-18** | Free text: "What do you notice about the pattern 'Ich habe ___'?" → open response |

For 7-10 and 11-14, the discovery question and options are **pre-generated** during lesson creation (no real-time AI needed). For 15-18, a quick Groq call evaluates their free-text response.

**System prompt addition for coaching generation:**

```
## Coaching Text Rules

For each chunk, generate a coaching introduction that the NPC will speak aloud.

COACHING TEXT must:
- Be in ${nativeLanguage} with ${targetLanguage} examples
- Reference the personal context if available
- Introduce the chunk naturally (not "New phrase: X")
- Be warm and conversational
- End naturally (the discovery question is separate)
- Be max 3-4 sentences for ages 7-10, max 5 for older
- Example: "So you want to tell people about Luna! In German, to say
  'I have a cat', you say: 'Ich habe eine Katze'. Listen closely!"

DISCOVERY QUESTION must:
- Ask the learner to NOTICE something (not test knowledge)
- Be non-threatening — wrong answers get encouragement
- For word-spotting: "Which word do you think means 'cat'?"
- For pattern-noticing: "What stays the same in all three phrases?"
- For guessing: "Can you guess what 'Katze' might mean?"

DISCOVERY OPTIONS must:
- Include 3 choices (one correct)
- Be single words or very short phrases
- The correct answer should be genuinely discoverable from context

DISCOVERY FOLLOW-UP must:
- Acknowledge ANY answer warmly
- Reveal/confirm the answer
- Highlight the reusable pattern
- Bridge to the practice: "Ready to practise?"
```

### File 3: `src/services/lessonAssembler.ts` — Build Coaching Steps

**Replace** the `buildIntroduceStep()` function with `buildCoachingStep()`:

```typescript
/**
 * Build a COACHING_CHAT step for a chunk.
 *
 * Replaces the old INFO step with an interactive coached discovery.
 * The coaching text was pre-generated by the AI during content generation.
 *
 * CRITICAL: This step awards 0 SunDrops. It's discovery, not assessment.
 * Getting the discovery question "wrong" is fine — the follow-up is
 * always encouraging regardless of the answer.
 */
function buildCoachingStep(chunk: GeneratedChunkContent): LessonStep {
  return {
    tutorText: chunk.coachingText || `Let's learn: "${chunk.targetPhrase}"`,
    helpText: `${chunk.targetPhrase} = ${chunk.nativeTranslation}`,
    activity: {
      type: GameActivityType.COACHING_CHAT,
      coachingText: chunk.coachingText || buildFallbackCoachingText(chunk),
      targetPhrase: chunk.targetPhrase,
      nativeTranslation: chunk.nativeTranslation,
      discoveryQuestion: chunk.discoveryQuestion || `What do you think "${chunk.targetPhrase}" means?`,
      discoveryOptions: chunk.discoveryOptions || [
        chunk.nativeTranslation,
        chunk.distractors[0],
        chunk.distractors[1],
      ],
      discoveryCorrectIndex: chunk.discoveryCorrectIndex ?? 0,
      discoveryFollowUp: chunk.discoveryFollowUp || `That's "${chunk.nativeTranslation}"! Great noticing!`,
      patternHighlight: chunk.patternHighlight || undefined,
      sunDrops: 0,
    },
  };
}

/**
 * Fallback coaching text if AI didn't generate it.
 * Still better than "New phrase: X" — at least it's conversational.
 */
function buildFallbackCoachingText(chunk: GeneratedChunkContent): string {
  return `Hey! Let's learn a new phrase. In the target language, we say: "${chunk.targetPhrase}" — which means "${chunk.nativeTranslation}". ${chunk.explanation || ''} Listen carefully!`;
}
```

### File 4: `src/components/lesson/CoachingChat.tsx` (NEW)

The component that renders the coaching chat step.

```typescript
/**
 * Coaching Chat Activity Component
 *
 * Renders an interactive coached discovery step:
 * 1. NPC speaks the coaching text (TTS) with mouth animation
 * 2. Discovery question appears with tap-to-choose options
 * 3. Learner taps an option (or types free text for 15+)
 * 4. Encouraging follow-up regardless of answer
 * 5. Pattern highlight (if available)
 * 6. "Ready to practise!" button
 *
 * This is NOT a quiz. There are no SunDrops, no failure state.
 * Every answer gets encouragement. The goal is DISCOVERY.
 */

interface CoachingChatProps {
  activity: CoachingChatActivity;
  onComplete: (success: boolean, sunDrops: number) => void;
  ageGroup: '7-10' | '11-14' | '15-18';
}
```

**Component phases:**

```
Phase 1: SPEAKING
  - TTS plays coaching text
  - NPC avatar mouth animation
  - Text appears progressively (like typing)
  - User can tap to skip TTS

Phase 2: DISCOVERY
  - Discovery question appears
  - Options appear (tap-to-choose) OR text input (15+)
  - User selects/types

Phase 3: REVEAL
  - Encouraging follow-up shown
  - If wrong: "Almost! The answer is X — but great guess!"
  - If right: "Exactly right! You're a natural!"
  - Pattern highlight appears (e.g. highlighted text showing the frame)
  - TTS plays the target phrase one more time

Phase 4: READY
  - "Let's practise! 💪" button
  - Tapping calls onComplete(true, 0)
```

**Visual treatment for discovery options:**

```
After selecting (regardless of correct/wrong):

CORRECT:
  [ ✅ Katze ] [ Habe ] [ Ich ]
  "That's right! 'Katze' means cat!"

WRONG:
  [ Habe ] [ Katze ← ] [ Ich ]
  "Good guess! Actually 'Katze' means cat. 'Habe' means 'have'!"
  (The correct answer gets a gentle highlight, no red/failure)
```

## Coaching Text vs Coaching Chat: The Distinction

| Aspect | Coaching Text (Phase 2.0.7 — existing) | Coaching Chat (Phase 3 — new) |
|--------|----------------------------------------|-------------------------------|
| What | Pre-generated monologue | Interactive exchange |
| Interaction | None — listen and continue | Discovery question with tap/type response |
| Graded? | No | No |
| AI model | Smart model (during generation) | Pre-generated options (no real-time AI for 7-14) |
| Step type | Was part of INFO | New COACHING_CHAT type |
| Personalised | References interests | References personal context from pre-lesson chat |

Phase 3 subsumes the Phase 2.0.7 `coachingText` concept. The coaching text becomes the spoken introduction within the coaching chat step.
